# ICON Activewear — Full-Stack E-Commerce Platform (Dubai, UAE)

A high-performance commercial e-commerce web application engineered for activewear retail in the UAE, featuring responsive catalog browsing, real-time cart handling, custom backend APIs, and secure role-based access control.

---

## 📌 Project Status & Confidentiality Notice

> **Acquired / Commercial Project Notice:**  
> This custom e-commerce solution was designed, developed, and delivered for a commercial client in Dubai, UAE. Following the business acquisition and transfer of software ownership, the production database, proprietary source code, and live environment have been transitioned to the buyer. This repository serves as a technical architecture overview and portfolio case study.

---

## 🛠 Tech Stack

* **Frontend:** React 18 | TypeScript | Tailwind CSS | Vite | Framer Motion
* **Backend & APIs:** Node.js | Express.js | RESTful APIs
* **Database & Auth:** Google Firebase Firestore | Firebase Authentication
* **Architecture:** Role-Based Access Control (RBAC) | Micro-Services Architecture

---

## ✨ Technical Highlights & Architecture

* **UAE-Tailored E-Commerce Experience:** Built a responsive catalog browsing experience with product quick-view, dynamic cart drawer, and multi-currency checkout support.
* **Real-Time Database Architecture:** Integrated Google Firebase Firestore for production, architecting real-time document creation and persistent order processing with zero data loss during server reboots.
* **Secure Backend APIs:** Designed custom Node.js/Express backend APIs with server-side validation against price tampering, automated cart calculation, and custom discount coupon engines.
* **Authentication & RBAC:** Implemented secure Firebase Authentication and Role-Based Access Control (RBAC), cleanly separating customer order histories from store-owner administrative analytics and order-status management workflows.
* **High-Performance UI/UX:** Optimized user interface with Tailwind CSS and smooth drawer animations, achieving sub-second load times and mobile-first shopping navigation.
